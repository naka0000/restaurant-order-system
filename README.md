# 飲食店オーダーシステム

小型飲食店向けのシンプルなオーダー管理システムです。スマートフォンやタブレットで注文を受け、スタッフ間で共有できます。

## 特徴

- 📱 スマートフォン対応のレスポンシブデザイン
- 🍽️ 直感的な注文入力インターフェース
- 👥 リアルタイムでの注文共有
- 🔄 注文ステータス管理（受付→調理中→完成→提供済）
- 📊 Google スプレッドシートとの連携（設定後）

## 使用方法

1. `index.html` をブラウザで開く
2. 「注文入力」タブで新しい注文を入力
3. 「注文管理」タブで注文一覧とステータス管理

## Google スプレッドシート連携設定

現在はサンプルデータで動作しますが、実際のGoogle スプレッドシートと連携するには：

1. Google Cloud Console でプロジェクトを作成
2. Google Sheets API を有効化
3. API キーを取得
4. Google スプレッドシートを作成し、IDを取得
5. `index.html` の以下を編集：
   ```javascript
   const SHEET_ID = 'YOUR_GOOGLE_SHEET_ID_HERE';
   const API_KEY = 'YOUR_GOOGLE_API_KEY_HERE';
   ```

## スプレッドシート形式

| A列 | B列 | C列 | D列 | E列 | F列 |
|-----|-----|-----|-----|-----|-----|
| 注文ID | 日時 | テーブル | 注文内容 | 特記事項 | ステータス |

## ブラウザ対応

- Chrome, Firefox, Safari, Edge
- iOS Safari, Android Chrome
- レスポンシブデザインでスマートフォン最適化

## カスタマイズ

- テーブル番号は `index.html` の select オプションで変更可能
- カラーテーマは CSS で調整可能
- メニュー項目の事前設定も可能
